# Random Variables & Distributions Scripts

Runnable examples for [`notes/random_variables_and_distributions`](../../notes/random_variables_and_distributions/README.md).

This folder contains PMF/PDF/CDF demonstrations, moments and shape summaries, z-scores, observed-vs-theoretical comparisons, and common discrete/continuous distribution families. Sampling-reference distributions such as Student's t, chi-square, and F are kept in the sampling unit.
