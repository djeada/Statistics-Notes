# Distribution Foundations

These notes introduce the common language used by every distribution-specific chapter.

## Reading Order

1. **[Introduction to Distributions](introduction_to_distributions.md)** — random variables, mass/density functions, and cumulative distributions.
2. **[Statistical Moments](statistical_moments.md)** — expectation, variance, skewness, kurtosis, and moment-generating functions.
3. **[Normal Curve and Z-Scores](normal_curve_and_z_score.md)** — intuitive normal-curve calculations and standardization.
4. **[Central Limit Theorem](central_limit_theorem.md)** — the sampling-distribution bridge to inference.

## Scope Boundary

`normal_curve_and_z_score.md` is an introductory calculation-oriented treatment. The formal distribution-specific formulas and properties are collected in **[Normal Distribution](../continuous_distributions/normal_distribution.md)**. Keeping those roles separate reduces duplicated explanations while preserving an accessible introduction.

Return to the **[Probability Distributions index](../README.md)** for the discrete and continuous families.
