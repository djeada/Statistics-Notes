# Discrete Distributions

These models describe integer-valued counts generated by different experimental structures.

| Modeling question | Distribution | Random variable used in these notes |
|---|---|---|
| How many successes occur in exactly $n$ independent Bernoulli trials? | [Binomial](binomial_distribution.md) | number of successes |
| How many trials are needed for the first success? | [Geometric](geometric_distribution.md) | trial number of first success |
| How many trials are needed for the $r$-th success? | [Negative binomial](negative_binomial_distribution.md) | trial number of the $r$-th success |
| How many events occur in an interval under a constant-rate Poisson process? | [Poisson](poisson_distribution.md) | event count |

## Connections

- The geometric distribution is the $r=1$ special case of the negative-binomial convention used here.
- A Poisson distribution can approximate a binomial count when $n$ is large, $p$ is small, and $np$ remains moderate.
- “Success” is just the event being counted. A failure can be relabeled as a success if that is the event of interest.

Before using a negative-binomial formula from another source or software package, verify whether it counts total trials or failures before the $r$-th success.
