## Terminology Boundary

Descriptive statistics summarize the data actually observed. Inferential statistics add a probability model and a sampling argument to reason about a population or data-generating process. Keeping that distinction explicit makes later concepts such as standard errors, confidence intervals, and p-values much easier to interpret.
