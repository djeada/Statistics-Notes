# Random Variables & Distributions Notebooks

Interactive companions for [`notes/random_variables_and_distributions`](../../notes/random_variables_and_distributions/README.md). The introduction notebook provides the unifying PMF/PDF/CDF view; the remaining notebooks explore common univariate families. Sampling-reference distributions are kept in the sampling unit.

The statistical-moments and normal-curve/z-score notebooks cover moments, the MGF, standardization, and percentile calculations. Each family notebook checks its hand-rolled PMF/PDF/CDF against `scipy.stats` and ends with a seeded simulation.
