# Exercises

Practice sets follow the same dependency-aware curriculum as the notes. Every unit has one exercise file per note, and every problem has a worked solution by hand (the `## Solutions` or `## Worked solutions` section at the end of the file). Numerical answers were checked in Python.

The time-series sets include hand calculations, simulation tasks, figure interpretation, and temporal backtesting. Each set points to the script that generated its teaching figures.
